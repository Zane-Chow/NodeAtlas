# Stage One Delivery Roadmap

**Spec:** `docs/superpowers/specs/2026-09-17-server-control-panel-design.md`

阶段一按五个可独立运行、可审阅的里程碑交付。每个里程碑开始前，根据已经存在的代码编写独立 TDD 实施计划。

1. **项目基础、双数据库与管理员认证**
   - Go/React 工程、配置、SQLite/MySQL 连接与迁移、首次初始化、环境变量初始化、登录、Session、CSRF、基础应用壳和嵌入式前端。
2. **服务商连接、Mock Provider 与统一清单**
   - 凭据加密、Provider 契约与注册表、多个 Mock 连接、连接测试、持久任务队列、定时/手动同步、统一服务器列表和详情。
3. **电源操作与实时状态**
   - 开机/关机/重启状态机、幂等、服务器级互斥、远端状态验证、操作记录、审计和 SSE 更新。
4. **三级控制台与备份恢复**
   - 控制台能力探测、一次性票据、内嵌 WebSocket 代理、新窗口链接、服务商后台回退、应用级加密备份、校验和跨数据库恢复。
5. **完整界面、发行与阶段一验收**
   - 总览、响应式交互、设置页、单文件跨平台构建、Docker Compose SQLite/MySQL 两种配置、端到端测试、运维文档和阶段一验收。

里程碑 2–5 必须保持已批准设计中的 API、安全和数据语义。若实现中发现需要改变这些边界，应先更新设计并获得确认。
